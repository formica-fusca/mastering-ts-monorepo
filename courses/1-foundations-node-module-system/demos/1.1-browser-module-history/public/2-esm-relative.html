2 — A specifier is a URL

<script type="module" src="./js/esm-app.js"></script>

// inside esm-app.js
import { greet } from './esm-lib.js'

The dependency is now declared, and the browser resolves it with the only algorithm it has: URL resolution. ./esm-lib.js is resolved relative to the importing module's own URL, producing http://localhost:8080/js/esm-lib.js, and fetched over HTTP.

What to notice

Note the extension. Drop the .js from the import in js/esm-app.js and the browser requests /js/esm-lib and gets a 404 — it does not guess extensions. This is the same rule that makes moduleResolution: "nodenext" demand .js in TypeScript source (lesson 3.2).

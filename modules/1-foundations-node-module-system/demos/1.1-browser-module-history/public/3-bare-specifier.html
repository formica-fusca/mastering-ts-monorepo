The wall

3 — import { greet } from 'esm-lib'

Exactly what you write in Node every day. In a browser it is a hard error, and the module never runs.

<script type="module">
  import { greet } from 'esm-lib'   // ← no ./ and no .js
</script>

Console (authoritative — open DevTools)

If this text never changes, the module never executed. That is the point. Check the console for: TypeError: Failed to resolve module specifier "esm-lib". Relative references must start with either "/", "./", or "../".

Why

'esm-lib' is not a URL and not relative to one. The browser has no filesystem to walk, no node_modules convention, and no package.json to read an "exports" field from. There is simply no algorithm available to turn that name into a location — so it refuses.

Notice too that nothing appeared in the server log for this page beyond the HTML itself. Resolution failed before any fetch was attempted.

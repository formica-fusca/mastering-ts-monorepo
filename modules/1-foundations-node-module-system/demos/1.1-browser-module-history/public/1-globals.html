1 — Script tags and globals

This is the whole model. Two files, loaded in order, communicating through the global object. There is no module system, no import, no dependency — just window.

<script src="./js/legacy-lib.js"></script>
<script src="./js/legacy-app.js"></script>

Output

(waiting)

What to notice

The dependency between these two files exists only in your head and in the order of the tags. Nothing declares it. Nothing enforces it. Swap the two script tags and read the console.

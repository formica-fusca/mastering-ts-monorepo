5 — Pricing Node's algorithm over a network

Node resolves import 'greeter' by probing the filesystem and walking up. Failed probes cost microseconds, so the algorithm is cheap.

This page performs the same sequence of lookups over HTTP. Every request under /simulate/ is delayed by 50 ms — one plausible round trip.

What to notice

Three round trips to resolve one import — and the resolved file has imports of its own, which start the same sequence again. The waterfall is as deep as your dependency tree. That is the argument that ended the discussion: an algorithm that is elegant on a filesystem is pathological over a network.

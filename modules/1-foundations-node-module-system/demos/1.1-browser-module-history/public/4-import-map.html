<script type="module">
  import { greet } from 'esm-lib'   // ← identical to page 3

Same import, now legal. The map is a complete specifier-to-URL table, known before the first import runs. No probing, no package.json fetch, no walking up directories.

The comparison worth holding

An import map and a package.json "exports" field solve the same problem — mapping a name to a location — with the authority inverted. "exports" lets the package decide, at resolution time, after being found. An import map makes the page decide, upfront, before anything is fetched. The browser's constraint is latency, so it must know everything in advance.
